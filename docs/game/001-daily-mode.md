# 每日模式设计

> 本文档详细定义每日模式的游戏逻辑和实现细节。
> 返回 [AGENTS.md](../../AGENTS.md)

---

## 一、核心规则

| 规则 | 说明 |
|------|------|
| 目标选定 | 每日 00:00（UTC+8）从 `active`/`verified` 状态 VTuber 中随机选取 |
| 全球统一 | 所有玩家面对同一目标 |
| 尝试次数 | 默认 8 次（可在配置中修改） |
| 时间限制 | 日内不限时，次日 0 点重置 |
| 防作弊 | 目标 ID 在服务端校验，前端不存储 |

---

## 二、每日目标刷新机制

### 2.1 刷新流程

```
每日 00:00 (UTC+8)
    ↓
检查当日是否已有目标（防重复执行）
    ↓
从候选池随机选取 VTuber
    ↓
写入 daily_target 表
    ↓
记录操作日志
```

### 2.2 候选池筛选规则

```java
// 伪代码
List<Vtuber> candidates = vtuberMapper.selectList(
    new QueryWrapper<Vtuber>()
        .in("data_status", "active", "verified")
        .eq("activity_status", "active")  // 排除已毕业
        .notIn("id", recentTargetIds)     // 排除近30天已选
);

// 优先选择 verified，其次 active
```

### 2.3 排除近期重复

| 规则 | 说明 |
|------|------|
| 排除天数 | 近 30 天 |
| 查询方式 | 查询 `daily_target` 表近 30 天记录 |
| 兜底策略 | 如果候选池为空，放宽到 60 天，再 90 天 |

---

## 三、游戏会话管理

### 3.1 会话标识

- 每日模式无需显式创建会话
- 通过 `user_id + target_date` 唯一确定一局游戏
- 同一用户同一天只能有一局每日模式游戏

### 3.2 状态存储

| 存储位置 | 内容 | 说明 |
|----------|------|------|
| 服务端数据库 | game_record 表 | 持久化记录 |
| 前端 LocalStorage | 当前猜测进度 | 断线恢复 |
| 前端内存 | 当前输入状态 | 临时状态 |

### 3.3 断线恢复流程

```
用户刷新页面
    ↓
前端读取 LocalStorage 中的进度
    ↓
调用 GET /api/game/daily 获取最新状态
    ↓
服务端返回 hasPlayed / attemptsUsed / guesses
    ↓
前端恢复游戏界面
```

---

## 四、猜测提交流程

```
用户输入 VTuber 名字
    ↓
前端调用搜索 API 获取候选列表
    ↓
用户选择或确认目标
    ↓
前端提交 POST /api/game/daily/guess
    ↓
服务端校验：
  - 用户凭证有效性
  - 是否已猜过该 VTuber
  - 是否还有剩余次数
    ↓
服务端计算对比结果
    ↓
更新 game_record（guesses JSON 追加）
    ↓
返回对比结果
    ↓
前端展示动画和提示
```

---

## 五、胜负判定

### 5.1 胜利条件

- 任意一次猜测完全匹配目标 VTuber
- 立即返回 `isCorrect: true, isGameOver: true, isWin: true`

### 5.2 失败条件

- 用完所有尝试次数仍未猜中
- 第 8 次猜测后自动判定失败
- 返回目标 VTuber 信息（揭晓答案）

### 5.3 边界情况处理

| 场景 | 处理方式 |
|------|----------|
| 重复猜测同一 VTuber | 返回 409 错误，提示已猜过 |
| 次数用完后继续猜测 | 返回 400 错误，提示游戏已结束 |
| 跨日继续游戏 | 自动视为新一天，重置进度 |

---

## 六、防作弊措施

| 措施 | 说明 |
|------|------|
| 服务端校验 | 目标 ID、猜测结果均在服务端判定 |
| 不下发答案 | 每日目标信息不返回具体 VTuber 数据 |
| 频率限制 | 同一 IP 每分钟最多 60 次请求 |
| 会话隔离 | 每日模式通过 user_id + date 隔离，无法推测 |

---

## 七、配置项

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| daily.maxAttempts | 8 | 每日最大尝试次数 |
| daily.excludeRecentDays | 30 | 排除近期已选天数 |
| daily.resetHour | 0 | 每日重置小时（UTC+8） |
