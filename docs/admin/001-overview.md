# 运营后台设计总览

> 本文档概述运营后台的功能模块和界面设计原则。
> 返回 [AGENTS.md](../../AGENTS.md)

---

## 一、功能模块

| 模块 | 功能 | 优先级 |
|------|------|--------|
| 数据看板 | 各状态 VTuber 数量统计、今日游戏数据 | P0 |
| VTuber 管理 | 浏览全量池、挑选进候选、编辑属性、核实数据 | P0 |
| 爬虫监控 | 查看爬虫进度、手动触发、错误日志 | P1 |
| 每日目标 | 查看历史每日目标、手动调整（紧急情况） | P1 |
| 题库管理 | 管理题库标签、编辑筛选规则 | P2 |
| 用户管理 | 查看用户列表、封禁违规用户 | P2 |
| 操作日志 | 查看所有操作记录 | P1 |

## 二、页面结构

```
/admin
├── /login              # 登录页
├── /dashboard          # 数据看板
├── /vtuber             # VTuber 管理
│   ├── /raw            # 全量池（raw 状态）
│   ├── /candidate      # 候选队列
│   ├── /active         # 正式池
│   └── /{id}           # VTuber 详情/编辑
├── /crawler            # 爬虫监控
├── /daily-target       # 每日目标管理
├── /pool-tag           # 题库管理
├── /user               # 用户管理
└── /logs               # 操作日志
```

## 三、核心界面设计

### 3.1 VTuber 管理列表页

**功能：**
- 分页浏览 VTuber 列表
- 按状态筛选（raw/candidate/active/verified）
- 按关键词搜索
- 批量操作（提升状态、加入候选）

**关键列：**

| 列 | 说明 |
|----|------|
| 头像 | 小图预览 |
| 名称 | 中文名 + 英文名 |
| 团体 | 所属团体 |
| 数据状态 | 标签显示（raw/candidate/active/verified） |
| 数据来源 | crawler/manual/admin |
| 锁定字段数 | 显示 🔒 数量 |
| 操作 | 查看/编辑/提升状态 |

### 3.2 VTuber 编辑页

**布局：**

```
┌─────────────────────────────────────────┐
│  噶呜·古拉 (Gawr Gura)      [保存] [取消] │
├─────────────────────────────────────────┤
│  基础信息                                │
│  ├─ 中文名: [噶呜·古拉        ] 🔒      │
│  ├─ 英文名: [Gawr Gura         ]        │
│  ├─ 日文名: [がうる・ぐら       ]        │
│  └─ 别名:   [Gura, 鲨鲨        ]        │
├─────────────────────────────────────────┤
│  属性信息                                │
│  ├─ 出道年份: [2020    ] 🔒            │
│  ├─ 地区:     [英语圈  ▼]               │
│  ├─ 团体:     [Hololive EN ▼]           │
│  ├─ 发色:     [蓝, 白    ] 🔒           │
│  ├─ 粉丝名:   [Shrimp    ]              │
│  └─ ...                                  │
├─────────────────────────────────────────┤
│  数据来源: crawler  |  锁定字段: 3 个     │
│  [解锁全部字段]  [标记为已核实]            │
└─────────────────────────────────────────┘
```

**交互规则：**
1. 每个字段显示当前值和数据来源
2. 已锁定的字段显示 🔒 图标
3. 修改字段后自动加入 `locked_fields`
4. 提供「解锁」按钮，允许爬虫重新覆盖
5. 保存时记录操作日志

## 四、权限设计

### 4.1 角色定义

| 角色 | 权限 |
|------|------|
| admin | 所有权限 |
| operator | VTuber 管理、爬虫监控、查看日志 |

### 4.2 第一期实现

- 单一 admin 账号
- 账号密码存储于数据库（BCrypt 加密）
- JWT Token 鉴权，有效期 24 小时

## 五、操作日志记录

### 5.1 记录内容

| 操作 | 记录字段 |
|------|----------|
| 编辑 VTuber | 操作人、目标、修改字段、旧值、新值 |
| 提升状态 | 操作人、目标、原状态、新状态 |
| 解锁字段 | 操作人、目标、解锁字段列表 |
| 手动触发爬虫 | 操作人、触发范围 |

### 5.2 日志查询

- 按操作人筛选
- 按目标类型/ID 筛选
- 按时间范围筛选
- 导出 CSV（远期）
