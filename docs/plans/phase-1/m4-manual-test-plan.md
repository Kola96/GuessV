## 一、测试前准备

### 方式 A：前后端分离（推荐开发调试）

```bash
# 终端 1：后端
cd backend && mvn spring-boot:run -Dspring-boot.run.profiles=dev

# 终端 2：前端（热更新）
cd frontend && npm install && npm run dev
```

浏览器访问 **http://localhost:5173**

### 方式 B：单 Jar 集成（验证生产部署形态）

```bash
# 构建前端
cd frontend && npm run build

# 拷贝到后端 static
# Windows:
Remove-Item -Recurse -Force ../backend/src/main/resources/static -ErrorAction SilentlyContinue
Copy-Item -Recurse dist/* ../backend/src/main/resources/static/
# Linux:
rm -rf ../backend/src/main/resources/static && cp -r dist/* ../backend/src/main/resources/static/

# 启动后端（内嵌前端）
cd ../backend && mvn spring-boot:run -Dspring-boot.run.profiles=dev
```

浏览器访问 **http://localhost:8080**

## 二、测试用例

### 用例 1：首次访问 - 昵称设置

打开页面，应看到：
- 深蓝紫背景 + 紫粉渐变 Logo "GuessV"
- 昵称输入框 + "开始游戏" 按钮 + 🎲 随机按钮 + "直接随机进入" 链接

操作：
- 输入 2-16 字符昵称 → 点"开始游戏" → 进入游戏页面
- 或点 🎲 自动填入随机昵称
- 或点"直接随机进入"跳过输入

**预期**：进入后顶栏显示昵称#游戏ID，看到每日模式游戏页。

### 用例 2：敏感词昵称被拒

输入"赌博王" → 点开始 → 应显示红色错误提示 + 输入框抖动。

### 用例 3：每日模式 - 完整一局

1. 在输入框输入"gura" → 下拉出现搜索建议
2. 点击建议中的 VTuber → 猜测卡片从下方滑入
3. 卡片内属性逐行揭示（stagger 动画）
4. 观察：
   - 匹配属性绿色高亮 ✓
   - 部分匹配橙色 ◐
   - 不匹配灰色 ✗
   - 出道年份箭头 ↑↓
5. 继续猜测直到猜中或用完 8 次

**预期**：
- 猜中 → 🎉 彩花动画 + "猜对了！用了 X/8 次"
- 用完 → 😢 + 答案揭晓（头像+名字）

### 用例 4：重复猜测被拒

猜过一个 V 后再次输入同名 V → 应显示"你已经猜过"错误提示。

### 用例 5：单人模式 - 题库选择

点顶栏"单人" → 看到 6 个题库卡片：
- 全量 / 日V / 国V / 英语圈 / Hololive / Nijisanji
- 每个卡片显示 VTuber 数量
- 国V 和 Nijisanji 显示 0（灰色不可点）

### 用例 6：单人模式 - 完整一局

1. 点击"全量" → 开始新局
2. 输入猜测 → 对比卡片
3. 猜中或用完后 → "再来一局"按钮
4. 点击重开 → 回到题库选择

### 用例 7：断线恢复

1. 玩到中途（猜了 2 次）
2. 刷新页面
3. **预期**：之前的猜测记录恢复显示

### 用例 8：SPA 路由刷新

1. 在单人模式页面（/single）按 F5 刷新
2. **预期**：不 404，正确回到单人页面

### 用例 9：移动端适配

用浏览器开发者工具切到手机视图（375px 宽）：
- 布局应全宽适配
- 属性卡片可能变为 2 列
- 输入框触屏友好

### 用例 10：单 Jar 部署验证（方式 B）

按方式 B 启动后访问 http://localhost:8080：
- 前端页面正常加载
- /single 路由刷新不 404（SPA fallback 生效）
- API 正常工作

## 三、视觉检查清单

| 检查项 | 预期 |
|--------|------|
| 背景色 | 深蓝紫黑（#0f0a1e），有微妙渐变光晕 |
| 卡片 | 半透明深紫底 + 模糊背景 |
| 主色 | 紫粉渐变（Logo、按钮） |
| 匹配色 | 绿（exact）/ 橙（partial）/ 灰（none） |
| 字体 | Noto Sans SC（中文清晰） |
| 卡片入场 | 从下方滑入 + 淡入 |
| 属性揭示 | 逐行 stagger 出现 |
| 胜利动画 | 彩花粒子从顶部洒落 |
| 失败揭晓 | 答案卡从下滑入 |
